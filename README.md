## 安装与调用

下载人物 ZIP 并解压，将含 SKILL.md 的整个目录放入 Codex 的 ~/.codex/skills/，然后开启新会话。references 等支持材料须一起保留。

带上目标、事实、限制和可承担代价，提出“用某某的视角分析这个问题，给出判断依据、具体行动、验证方式与失败边界”。一次比较2—3个视角，以实际证据选择行动。

## 来源与边界

这是已有技能的发布整理，未重新核查人物的最新观点。原文、历史记述、外部评价与现代模型推断的区分见各包内文件；模拟表达不等于人物真实发言。各包记录实际阅读范围、研究时间与验证局限。
